# Support

- Use [GitHub Discussions](https://github.com/egore4606/schulmanager-calendar-sync/discussions) for installation help, configuration questions, and ideas.
- Open a structured issue for reproducible bugs in the latest release.
- Use private vulnerability reporting for security problems.

This is a community project. It cannot provide Schulmanager account support, recover access tokens, administer Google Cloud projects, or guarantee compatibility with undocumented upstream changes.

Before asking for help, run `npm run verify`, inspect the local health endpoint, and review container logs. Redact all personal and secret information.
